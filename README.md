## 🤖 Automated with LeetSync

This repository is connected to my **LeetCode account through LeetSync**.

Whenever I solve a LeetCode problem, LeetSync automatically pushes the solution to this repository.

### 🔄 Workflow

```text
        🧑‍💻
     Solve Problem
          │
          ▼
      🟠 LeetCode
          │
          ▼
       ⚡ LeetSync
          │
          ▼
     🐙 GitHub Repository
          │
          ▼
      📚 DSA Archive
```

This allows the repository to grow automatically as I continue practicing.
